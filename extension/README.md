# Resume Chrome 侧边栏试用版

## 加载

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择仓库里的 `extension/` 目录。
5. 点击扩展图标打开 Resume 侧边栏。

扩展只申请 `storage` 和 `sidePanel` 权限，不读取网页、不接入 AI、不申请网站访问权限。

## 当前试用范围

- 简历方向：自动保存、改名、新建模板副本、删除（至少保留一份）。
- 纸面编辑：沿用冻结的 A4、字体、内容结构和 L-19 自动排版。
- 快捷键：沿用纸面编辑快捷键；`⌘F` 打开简历方向室；不提供 `⌘S`。
- 导出：调用 Chrome 自带打印，用户在打印界面选择“另存为 PDF”。
- 观看：整页、100% 和显示缩放；缩放不改变排版或 PDF。

真实中文输入法、Chrome 快捷键、侧边栏宽度和打印结果必须在当前 Mac 上实际试用。
