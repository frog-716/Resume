## 0. 边界：什么能动，什么不能动

**冻结不变（SPEC 已确认）：**

- A4 纸面：210×297mm、四边 9mm 边距、四个固定板块及顺序（L-01/L-02/L-06/L-12/D-06）
- L-19 自动排版算法、字号范围 8.50–10.50pt、条目/日期固定 +0.5pt、姓名 18pt / 联系 8.5pt / 分区标题 12pt（L-06/L-09/L-11/L-19）
- 字体分轨：中文苹方、英文与数字 Times New Roman（L-14）；GitHub 白猫图标（D-02/L-16）
- 快捷键集合不新增：⌘F 方向室、⌘Z 撤销、⌘B 加粗、Esc 返回；不提供 ⌘S（E-05/E-06/§5）
- 保存状态必须对应真实写入，失败显示原因且可重试，不得虚假"已保存"（S-02）
- 方向室内容与行为：名称、分钟级编辑时间、A4 缩略图、时间倒序、搜索、改名、新建、删除；窄栏一列宽栏多列；点纸面进入、Esc 返回；不显示产品大标题（S-03/S-06/S-07）
- 打印：`@media print` 仅输出 A4、隐藏全部 UI（L-04）
- 联系区两行规则与溢出暂停（L-13）

**本提案只改：** 顶栏、纸面外的背景与投影、视图胶囊、方向室外观、弹窗、toast、排序手柄、联系添加菜单、超页边界提示、焦点态、空态、动效。

## 1. 设计输入

### 1.1 品类与标杆

品类：**浏览器侧边栏里的文书工具**——同时具备三种基因：侧边栏实用扩展（窄幅、常驻、随叫随到）、文档编辑器（纸面即内容）、版本/方向管理（多稿并行）。这个品类没有现成的"标准答案"，标杆要从三类里各取一家拆：

| 标杆 | 拆出来的要点 | 对本产品的意义 |
| --- | --- | --- |
| Linear（现代专业工具） | 近单色 + 单一强调色；1px 分隔线而非阴影与间距；数据面零圆角、只有交互件与浮层有圆角；键盘优先、约 200ms ease-out；内联反馈、无转圈；LCH 感知均匀色彩、主题仅 3 组变量 | "工具完成度"的地板：定义了侧边栏里高密度却不乱的画法 | 
| iA Writer / Ulysses（文书工具） | 纸面是唯一主角，chrome 退到近乎消失；Ulysses 的资料库是"分组列表"而非卡片墙；编辑区专注模式 | "文书工具"的正确姿势：UI 不与内容争注意力 |
| 编辑部/书籍装帧（印刷传统） | 刊头、目录页、folio 页码、细规则线分区、校对红、双线 | 本产品与"付印"的真实关系：整款工具服务于一张要打印的纸 |

> 标杆栏说明：以上为凭记忆与公开设计资料整理，**未取实时截图核验**；字体、色彩、主视觉三栏在方向卡中标注为待验证，选定方向后补截图比对。

### 1.2 用户、场景与任务

- 用户：求职者本人，首版在本人 Mac + Chrome 自用；正在维护多个投递方向，改稿频繁、周期长
- 场景：Chrome 侧边栏（宽度约 320–800px，当前实现有 620/900px 两档响应式）；长时间专注编辑；随时打印导出
- 情绪与约束：简历是"要拿出去被评判的纸"，用户要的是**控制感与确定性**（自动保存真的在存、超页真的会拦、打印真的只出 A4），不是玩具感；数据纯本机，隐私敏感
- 主动作（按频率）：① 在纸面上改字 ② 切方向（⌘F）③ 打印 PDF ④ 新建/改名方向 ⑤ 撤销

### 1.3 调性（五刻度）

证据指向：编辑是专注正事 → 能量取**安静**；产品自己按 mm/pt 精度工作 → 完成度取**精致**；侧边栏窄 → 密度取**中**；文书工具 → 分量取**轻**；求职是正事 → 严肃度取**庄重**。用户点名要"极简专业、现代活泼、沉浸式暗色"等不同倾向，因此允许候选跨调性分布；每个方向仍需说出依据，不做无依据的默认。

### 1.4 当前实现的起点

当前 `extension/sidepanel.css` 是紫色浅色主题（`--purple:#6743a2`，承接 V34 原型），顶栏 54px、按钮 32px 高、方向室单/双列卡片、视图胶囊已按 Gemini 顾问意见收在纸面下方右侧。四个方向都以这套 DOM 结构为基底改造，不重写信息架构。

## 2. 四个设计方向

### 方向 A · 极简专业「纸面工坊」

**北极星：** 让 A4 纸是整间屋子里唯一的主角，其余一切像一张收拾干净的灰卡纸工作台。

**核心思路：** 删到不能再删。chrome 全部退为 1px 发丝线、白面与暖灰底的三层结构；彩色只保留一个"墨蓝"强调色，面积不超过画面 5%；唯一的投影给纸面——因为它真的是"放在台面上的一张纸"。

**生成引擎：** 材质 × 环境——灰卡纸工作台 + 一叠待打印的 A4 纸。圆角、描边、阴影的尺度都从"纸和台面"推出：控件圆角 8px（纸张的柔），投影只给纸（台面上的实物）。

**骨架与信息层级：** 顶栏一行（左：方向名 + 保存状态；右：方向室、打印 PDF）→ 纸面居中占据全部剩余空间 → 右下角浮动视图胶囊。方向室 = 宽栏双列 A4 缩略图网格（沿用 S-07 已确认结构），卡片即"一张小纸"，无边框、仅投影。首屏第一眼必须是纸，不是按钮。

**色彩规范：**

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 台面底 | `#F4F3F1` | 纸面外背景、纸面滚动区 |
| 面 | `#FFFFFF` | 顶栏、弹窗、控件底 |
| 墨 | `#23222A` | 主文字、主按钮 |
| 次 | `#6E6A75` | 辅助文字、占位符 |
| 线 | `#E3E1DC` | 1px 分隔、控件描边 |
| 强调（墨蓝） | `#3D5A80` | 主动作、选中态、焦点环 |
| 选中底 | `#E9EEF4` | 列表/控件选中背景 |
| 成功 | `#3E7C4F` | "已保存" |
| 危险 | `#B3382F` | 删除确认 |

**字体规范：** 界面 PingFang SC；方向名 16px/600，正文 13px/400，辅助 11px/400；所有数字（缩放比例、时间戳）`font-variant-numeric: tabular-nums`。字重只有 400/600 两档，层级靠字号与灰度不靠彩色。

**关键元素处理：**

- **顶栏**：白底、底部 1px 发丝线；方向名点击即改（悬停极淡底色 `#F7F6F4` + 文字光标）；保存状态 11px 灰色文字，"已保存"转成功绿，不加图标
- **纸面**：`box-shadow: 0 1px 2px #23222A14, 0 12px 32px -8px #23222A1F`——整站唯一阴影；滚动区即台面底色
- **视图胶囊**：白底 1px 边 8px 圆角，选中项灰蓝底 `#E9EEF4` + 墨蓝字；无玻璃拟态
- **方向室卡片**：无边框白卡 + 同款纸面投影；名称 13px/600，时间 10px 次级灰；悬停整卡提亮
- **弹窗/toast**：白面 1px 边 8px 圆角；toast 底部居中、墨底白字、无图标
- **排序手柄**：32px 白底方钮 1px 边，拖动时纸面该条目下沉 1px 并出现 2px 墨蓝插入指示线
- **超页边界**：保持现有橙色边界线语义，改为 `#B3382F` 校对红 + "暂停打印"小条，颜色更克制
- **联系添加菜单**：白底 1px 边小浮层，12px 文字，无阴影

**交互流程与反馈：** 保存状态三态淡入淡出（160ms）；⌘F 开合方向室用 120ms 淡入 + 纸面轻微后退感（不改动纸面本身）；新建方向弹窗内命名框自动聚焦；删除确认二次点击；缩放点击即改、读数直接跳字；全部反馈"当场发生"，不加 Toast 噪音。

**组件一致性规则：** 圆角三档（控件 8px / 纸面 2px / 胶囊 8px）；描边只有 1px 一种；阴影只允许纸面与卡片；动效全场 120–160ms ease-out；图标 1.5px 圆头线性单色。

**记忆点：** 双击纸面外任意处进入"只留纸"的专注态（顶栏与胶囊淡出 60%），动一下鼠标回来——不新增快捷键，符合 E-06。

**放弃：** 彩色标签、大圆角、渐变、玻璃拟态、emoji、暗色。

**适用场景：** 投金融、咨询、国企、研究机构；长时间连续改稿；想要"工具不打扰"的用户。最保守、最不会错的方向。

**落地可行性：** 高。改 `sidepanel.css` 变量层与少量组件样式，不动 HTML 结构；打印样式已强制白底，无回归风险。代价最低。

### 方向 B · 现代活泼「便签投递台」

**北极星：** 把"同时维护多个投递方向"变成一桌待办的便签——改简历像收拾桌面，轻快、有掌控感。

**核心思路：** 承认求职是件磨人的事，界面给一点情绪价值。暖奶油底 + 柿子橙强调 + 大圆角厚控件；方向室卡片做成"贴纸"（和纸胶带贴边、±1° 微旋转、名称可选手写感），每张方向是一个"投递任务"。活泼只发生在外围 chrome，**纸面保持绝对严肃**——白纸黑字不动，形成"外面轻松、里面专业"的反差。

**生成引擎：** 一个具体场景——傍晚书桌上摊开的简历、便利贴、胶带、马克笔。动效的手感从"拍便利贴"来：有弹性、会晃、但一下就能按住。

**骨架与信息层级：** 顶栏（方向名 + 保存状态做成"小灯笼"点亮态 + 方向室/打印）→ 纸面 → 右下"贴纸胶囊"（视图控件做成一张胶带贴纸）。方向室 = 便签卡网格：顶部一条和纸胶带、卡片微旋转、悬停时"被按平"（旋转归零 + 投影加深）。

**色彩规范：**

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 桌面底 | `#FBF7EF` | 全局背景 |
| 面 | `#FFFFFF` | 卡片、控件 |
| 墨 | `#2A251D` | 主文字 |
| 次 | `#7A7263` | 辅助文字 |
| 强调（柿子橙） | `#E8590C` | 主动作、焦点环、胶带点缀 |
| 强调深 | `#D9480F` | 悬停/按下 |
| 辅（鹅黄） | `#FFD43B` | 仅保存状态点、新建入口 |
| 线 | `#EADFC9` | 描边、分隔 |

**字体规范：** PingFang SC，界面字重偏重（名称 600、按钮 600）；正文 13px、辅助 11px；数字 tabular-nums。方向室卡片名称可用"手写感"系统字体栈（`"Xingkai SC","STXingkai",cursive` 回退 PingFang）做差异化——仅卡片，界面其余不用。

**关键元素处理：**

- **顶栏**：奶油底 + 底部 2px 双色线（橙/黄 2:6 分段），像桌沿；方向名悬停出现铅笔小圆钮
- **保存状态**：文字前加一颗鹅黄小圆点，"已保存"时圆点实心 + 文字"好啦，已保存"；失败变橙红 + 重试按钮做成可撕下的便签条
- **纸面**：投影比方向 A 更软更大（`0 16px 40px -12px #2A251D2E`），像真的放在桌上；滚动区露奶油底
- **视图胶囊**：14px 大圆角、2px 描边、白底；选中项柿子橙底白字
- **方向室卡片**：白卡 16px 圆角 2px 描边；顶部 48×14px 半透明橙黄"胶带"（`rotate(-2deg)`）；卡片体 `rotate(±0.6deg)` 交替；名称 14px/600；时间 10px；删除按钮悬停才出现（"撕下"动效：卡片向左一歪淡出，网格重排用 200ms 弹入）
- **弹窗**：16px 大圆角，标题前可加一个小图钉形装饰；主按钮柿子橙
- **排序手柄**：拖动时条目像被捏起（放大 1.5% + 投影加深），松手落定
- **超页边界**：橙红锯齿/胶带形提示条"超页啦，先删减再打印"，语气软但信息硬

**交互流程与反馈：** 新建方向：弹窗确认后卡片以 spring（`cubic-bezier(.34,1.56,.64,1)`，≤240ms）拍进网格并轻晃落定；保存成功小灯笼"亮"一下；⌘F 进出用推拉开了；删除有二次确认 + 撕下动画。所有弹性动效在 `prefers-reduced-motion` 下降级为淡入淡出。

**组件一致性规则：** 圆角两档（控件/卡片 14–16px、小件 10px）；描边 2px；阴影允许纸面、卡片、浮层三处；动效 200–240ms，弹性曲线只用于"进入/落定"；图标 2px 圆头线性。

**记忆点：** 新建方向时卡片"啪"地拍进网格——把"多方向投递"这件压力事变成有正反馈的动作。

**放弃：** 暗色（首版只做亮）、细发丝线、严肃商务腔、纸面内的任何活泼化。

**适用场景：** 投创意、市场、运营、内容岗；把求职当项目经营的阶段；心态轻松、想每天愿意打开的用户。投保守机构时可切回方向 A。

**落地可行性：** 中高。方向室卡片需加少量装饰层（胶带元素），需要 `sidepanel.mjs` 渲染卡片时多一个装饰节点；弹性动效纯 CSS；打印样式需加一条"方向室装饰不打印"（当前已整块隐藏，无实际回归）。主要成本在卡片重渲染逻辑的小改。

### 方向 C · 沉浸式暗色「暗房灯箱」（推荐）

**北极星：** 把屋子调暗，让白纸像灯箱上待审的校样一样浮起来；工具退到幕后，注意力全部落在纸上。

**核心思路：** 简历的终点是一张被评判的纸，那就给它一束光。暗色 chrome 用"微紫炭"而非纯黑（与现有紫色品牌资产 `#6743a2` 同族，延续辨识度），纸面成为画面里唯一的亮面——这就是"灯箱"。同时借 Linear 的纪律：近单色、1px 分隔、数据面零圆角、键盘优先、约 200ms ease-out、内联反馈无转圈。暗色不是氛围装饰，是让纸更突出的手段。

**生成引擎：** 材质 × 环境——暗房 / 灯箱校样台。光的逻辑决定一切：亮面只有纸，浮层（胶囊、抽屉）用半透明玻璃，其余面按"离光的距离"分三级明度。

**骨架与信息层级：** 暗色顶栏（左：方向名 + 保存状态；右：方向室、打印）→ 中央暗室中一张亮纸 → 右下玻璃视图胶囊。⌘F 方向室为**全宽抽屉**：暗底上 A4 缩略图排成一排小灯箱（纸比现在更亮），搜索框自动聚焦；Esc 返回时纸面轻轻回位。层级：纸（唯一亮面）> 当前操作控件 > 方向列表 > 辅助信息。

**色彩规范：**

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暗室底 | `#16151B` | 全局背景（微紫炭，非纯黑） |
| 浮层 | `#1E1D26` | 顶栏、弹窗、抽屉 |
| 纸 | `#FFFFFF` | A4 纸面（唯一亮面） |
| 线 | `#2E2C38` | 1px 分隔、控件描边 |
| 字 | `#E8E6EF` | 主文字 |
| 次 | `#9A96A8` | 辅助文字 |
| 强调（亮紫） | `#8E86F8` | 主动作、选中态、焦点环（暗底提亮，与品牌紫同族） |
| 强调悬停 | `#A29BF9` | 悬停态 |
| 选中底 | `#2A2838` | 选中背景 |
| 成功 | `#4CC38A` | "已保存" |
| 危险 | `#F76E6E` | 删除确认 |
| 纸缘光 | `#FFFFFF` 1px 高光线 + `0 0 0 1px #16151B, 0 24px 64px -12px #000000A6` | 纸面在暗室中的浮起 |

**字体规范：** 界面 `-apple-system, "SF Pro Text", "PingFang SC"`；方向名 15px/600，正文 13px/400，辅助 11px/400；数字 tabular-nums（缩放、时间戳）。字重两档（400/600），层级靠明度差：`#E8E6EF` / `#9A96A8` / `#6F6B7E` 三级灰。

**关键元素处理：**

- **顶栏**：`#1E1D26` + 底部 1px `#2E2C38`；方向名悬停出极淡紫色底；保存状态 11px，已保存 `#4CC38A`
- **纸面**：四周暗室 `#16151B`；纸缘一道 1px 亮线 + 大而柔的投影，像灯箱透光；100% 视图时纸撑满、暗室收窄为 8px 缝隙
- **视图胶囊**：半透明玻璃（`#1E1D26CC` + `backdrop-filter: blur(12px)`）+ 1px 边；选中项 `#2A2838` 底 + 亮紫字
- **方向室抽屉**：整幅 `#16151B`，顶部搜索框（`#1E1D26` 底、聚焦时亮紫描边）；缩略图卡片 = 暗底上一张更亮的纸（无投影、1px 边 `#2E2C38`，悬停提亮 4%）；时间戳 `#9A96A8` 11px tabular-nums
- **快捷键提示**：控件悬停/常驻显示 `<kbd>` 小键帽（`#1E1D26` 底 1px 边 4px 圆角 10px 字）——⌘F、⌘Z、Esc，把已有快捷键（E-05/E-06/§5）的存在感变成设计语言
- **弹窗**：`#1E1D26` 底 + 1px 边 + 12px 圆角，背后 60% 黑遮罩
- **toast**：底部居中，`#1E1D26` 底 1px 边；失败 toast 右侧"重试"为亮紫文字钮
- **排序手柄**：`#1E1D26` 底 1px 边；拖动时条目被"捏起"（`scale(1.01)` + 亮紫插入线）
- **超页边界**：暗室中一道 `#F76E6E` 细线 + "暂停打印"红字条——唯一允许的"红"
- **联系添加菜单**：`#1E1D26` 玻璃小浮层

**交互流程与反馈：** 保存状态：编辑中 → "保存中…"（`#9A96A8`）→ "已保存 ✓"（`#4CC38A` 勾形轻弹出）；失败保留输入 + 原因 + 重试。⌘F：抽屉左滑入 200ms ease-out + 纸面 `scale(.98)` 后退，搜索框自动聚焦，输入即时过滤；Esc 反向。新建方向：弹窗确认后新卡片从列表顶部淡入并排序就位。删除：二次确认（明确"不可恢复"）。缩放：读数直接跳。全程无转圈、无线性进度条——要么完成要么给出原因（S-02 纪律）。

**组件一致性规则：** 圆角——交互件 10px、浮层 12px、数据面（缩略图、列表行）**0–4px**；描边全场 1px；阴影只给纸面与浮层；动效全场 160–200ms ease-out，禁弹性曲线；图标 1.5px 圆头线性 `currentColor`。彩色预算：强调紫 ≤5%，红绿仅状态语义。

**记忆点：** 暗室 + 灯箱纸。晚上改稿时，屏幕里只有一张发光的纸——"整个世界暗下来，就为看清这一张"。

**放弃：** 渐变弥散光斑、发光边框、彩色标签墙、大圆角泡泡、转圈加载、浅色模式（首版单主题；`prefers-color-scheme: light` 用户由系统其他应用照顾，扩展内部保持一致）。

**适用场景：** 长时间连续编辑（尤其夜间）；频繁切换方向的投递高峰期；喜欢工具感与键盘流的用户；与 Chrome 深色主题并排使用时视觉连续。**打印流程不受影响**：`@media print` 已强制白底黑字并隐藏全部 UI，暗色只存在于屏幕态。

**落地可行性：** 中。纯 CSS 变量双套 + `<meta name="color-scheme" content="dark">` + 打印样式回归一条；HTML 结构不动（kbd 提示为可选增强）。主要工作量在变量梳理与暗底下对比度自检（正文对比 ≥ 4.5:1，辅助文字 ≥ 3:1），以及真机验证 Chrome 侧边栏暗色下的投影观感。与现有紫色品牌资产同族，延续成本最低。

### 方向 D · 编辑部「活字排版间」

**北极星：** 把整款工具当成一间小印刷社：界面用编辑部的语法（刊头、目录页、细规则线、校对红），纸面是唯一进入付印流程的物件。

**核心思路：** 这是四个方向里最"产品本格"的一个——Resume 的本质是排印一张要打印的纸，L-19 算法就是一套排印规则。那就把排印的尊严感做进 chrome：Times New Roman 做大字标题（与纸面西文字体同族，UI 与内容像同一家作坊出品）、细规则线分区、编号制（No.01、No.02）、朱砂校对红只点在主动作和关键状态上。它不是"复古皮肤"，是把"精确"可视化。

**生成引擎：** 设计运动/文化语法——书籍装帧与报纸编辑部。借它的语法（刊头、目录、folio、对版标记），不贴它的图案。

**骨架与信息层级（结构性突破）：** 顶栏做成**刊头**：方向名用 Times 17px 大字 + 下方一道双线（1px + 3px 间距 + 1px），保存状态像版权页小字。方向室改成**目录页**而非卡片墙：通栏列表行——每行 = 左侧小 A4 缩略图 + `No.01` 编号 + 方向名（Times 14px）+ 右侧分钟级时间戳右对齐，行间 0.5px 发丝线；宽栏时两列同款列表行（遵守 S-07 的窄列宽列规则）。视图胶囊改成纸面下方的"工具轨"，与刊头双线呼应。

**色彩规范：**

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸白底 | `#FBFAF7` | 全局背景（微暖纸白） |
| 面 | `#FFFFFF` | 纸面、控件 |
| 墨 | `#1F1C19` | 主文字、刊头 |
| 次 | `#6B655C` | 辅助文字、编号 |
| 线 | `#D8D3C8` | 0.5–1px 规则线 |
| 强调（朱砂） | `#C03A2B` | 主动作、校对红、焦点环 |
| 选中底 | `#F5E9E4` | 选中背景（朱砂 8% 调） |

**字体规范：** 刊头/方向名/编号 = `"Times New Roman", serif`（呼应纸面西文）；界面说明与正文 = PingFang SC 13px/400；分区标签类小字用 `letter-spacing:.08em` 的小型大写感处理。层级：刊头 17px → 方向名 14px → 正文 13px → 辅助 11px。

**关键元素处理：**

- **刊头顶栏**：白底；方向名 Times 17px（点击改名，悬停出现朱砂下划虚线）；下方双线；保存状态 11px"校对于 hh:mm"式表达（仍对应真实写入，S-02）
- **纸面**：投影全场最克制（`0 1px 3px #1F1C1914, 0 8px 24px -12px #1F1C1922`）；纸面外即纸白底，纸与背景几乎融为一体，靠投影分层
- **工具轨（视图胶囊）**：直角 4px、1px 墨字描边、白底；选中项墨底白字反白
- **方向室目录页**：列表行高 56px；编号 `No.01` 用次级色 Times；名称 14px；时间戳 11px tabular-nums 右对齐；行 hover 出 `#F5E9E4` 选中底；顶部搜索框做成"检索条"（直角 1px 边）
- **按钮**：直角白底墨字 1px 边；主按钮（打印 PDF）朱砂底白字——全站唯一的实心彩色块，像一枚付印章
- **弹窗**：白底 1px 边直角；标题 Times 15px；确认删除按钮朱砂
- **toast**：底部居中白底 1px 边直角，左侧一条 3px 朱砂竖线
- **排序手柄**：直角 1px 边小方钮；拖动时插入指示为 1px 朱砂线
- **超页边界**：朱砂 1px 实线 + "暂停付印"小白条（朱砂底白字）
- **联系添加菜单**：白底 1px 边直角小浮层

**交互流程与反馈：** ⌘F 开合方向室：目录行 40ms 阶梯淡入（从 No.01 起），像翻开目录页；保存成功后状态文字"校对于 hh:mm ✓"；新建方向弹窗确认后新行插到目录顶部并闪一次 `#F5E9E4`；删除二次确认；缩放读数跳字。全部 120–160ms，无弹性。

**组件一致性规则：** 圆角只两档（4px 近方 / 0 直角）；描边 1px；不用阴影分层，靠 0.5px 规则线与底色差分层；动效 120–160ms ease-out；不用成套图标库——用字符与编号（`⌕`、`＋`、`No.01`）承担图标职能，与"排印房"语气一致。

**记忆点：** 朱砂"打印 PDF"按钮 + 方向室目录页。每次导出都像在付印单上盖章。

**放弃：** 卡片网格、圆角、胶带/手写体、暗色、渐变、成套彩色图标。

**适用场景：** 把求职当作品打磨的用户；投设计、出版、学术、法律岗；追求辨识度与"作坊式专业"的用户。

**落地可行性：** 中高。字体用系统已有字体（Times New Roman + PingFang SC，纸面已在用），无新依赖；主要工作量：① 方向室由卡片网格改为列表行（`sidepanel.mjs` 渲染逻辑小改，S-07 的缩略图/时间/搜索/改名全部保留）② 0.5px 发丝线在 Retina 的 `transform: scaleY(.5)` 处理 ③ 刊头双线等细节。风险：chrome 里的 Times 与纸面西文可能"撞调"——靠字号与色彩区分（chrome 墨色小字 vs 纸面黑色正文）；窄栏 400px 下列表行需保证 13px 可读与缩略图 ≥ 56px 宽。

## 4. 推荐与理由

**推荐方向 C「暗房灯箱」，D 作为"要辨识度"时的备选。**

理由：

1. **任务适配最强。** 主动作是长时间盯着一张纸改字。暗色 chrome + 唯一亮面纸面，是把"内容即主角"做到最狠的一版；Linear 式的密度与键盘优先，正好服务侧边栏窄幅与已有的 ⌘F/⌘Z 投资。
2. **品牌延续成本最低。** 现有紫色资产（`#6743a2`）在暗底上提亮为 `#8E86F8`，用户对产品的既有认知不断裂；D 的朱砂、A 的墨蓝都要重新建立色彩身份。
3. **反馈纪律服务确定性。** 保存三态、失败重试、超页红线——暗底下这些状态反而更清晰（暗室里的红线和绿字比浅色底更醒目），契合 S-02"不许虚假已保存"的产品性格。
4. **打印零风险。** `@media print` 已强制白底黑字隐藏全部 UI，暗色只存在于屏幕态，不影响 L-04。
5. **落地路径最短。** 不动 HTML 结构与任何产品规则，主要是 CSS 变量双套 + 对比度自检 + 真机投影观感验证。

不选 A 的原因：它最安全，但和当前紫色浅色版差异最小，"美化"的收益也最小；它的价值在于作为 B/C/D 都做不下去时的保底。不主推 B 的原因：活泼感与"投保守机构"的核心场景存在张力，且手写体/胶带在窄侧边栏里空间成本高。不主推 D 的原因：辨识度最高但也是风险最集中的一版——chrome 里的 Times 与纸面西文同族，稍有不慎会"撞调"；目录页改造要动 `sidepanel.mjs` 的渲染逻辑。若用户明确想要"一眼和所有 AI 默认审美区分开"，选 D。

## 5. 四个方向共同遵守的可用性基线

1. 快捷键不新增、行为不变：⌘F 方向室、⌘Z 撤销、⌘B 加粗、Esc 返回；不提供 ⌘S（§5/E-05/E-06）
2. 纸面 9mm 边距、虚线框只显示/隐藏正文范围（L-12）、L-19 排版与字号范围不被任何视觉改动触碰
3. 保存状态真实可查，失败保留输入 + 原因 + 重试（S-02）；中文输入法 composition 期间不保存半句（E-04）
4. 方向室信息不省略：名称、分钟级时间、A4 缩略图、搜索、改名、新建、删除（S-07）；窄栏一列宽栏多列
5. 焦点可见（focus-visible 环，3px 或等效）、正文对比 ≥ 4.5:1、辅助 ≥ 3:1；数字一律 tabular-nums
6. `@media print` 仅输出 A4、隐藏全部 UI；任何方向的装饰元素都不得渗入打印
7. 空列表的编辑补充入口仅编辑时出现、不打印（E-06）；空字段与界面提示不进 PDF（D-07）
8. 零新增依赖：纯 HTML/CSS/JS 改造，主题用 CSS 自定义属性分层，不做构建期魔法
9. 所有动效在 `prefers-reduced-motion: reduce` 下降级为淡入淡出
10. 画面不出现"示例/示意图/未接入"类制作说明；演示数据用虚构稿

## 6. 选定之后的实施顺序（建议）

1. CSS 变量层：把 `sidepanel.css` 的紫色散点值收敛为一套语义变量（surface / ink / line / accent / state），四个方向共用同一套变量名，只换值——这是"改主题不改结构"的前提
2. 顶栏与保存状态（最高频可见）
3. 纸面背景与投影、视图胶囊
4. 方向室（卡片网格或目录页）
5. 弹窗、toast、排序手柄、联系添加菜单、超页边界
6. 动效与微反馈（三处基本动效：保存状态流转、⌘F 抽屉/列表入场、新建/删除的网格重排）
7. 真机验收：Chrome 加载 → 侧边栏宽度 320/480/800 三档 → 中文输入 → ⌘F/⌘Z/Esc → 拖拽排序 → 打印 PDF 白底核对 → 对比度自检

## 10. 联系图标光学归一 + 首屏纸面对齐 v34（2026-10-21 round 05）

用户两件事：① 联系五个图标"视觉太不协调，尺寸得修"；② 首屏 demo 的纸面（四大列表等）不是 v34 的真实渲染样，要按 v34 核对。

**① 图标光学归一（改渲染、不动美术）：**

- 根因：四个描边图标用 `24×24` viewBox 自带内边距，白猫用 `16×16` 且路径几乎填满；同处 14px 容器 → 墨迹尺寸参差（电话 83%、邮箱高度仅 54%、白猫近 100%）。
- 方案：不做等比例缩放（会把白猫缩得比电话小、横向图标显小），而是**光学归一**——每个图标把自身墨迹盒映射到一个居中的正方形 viewBox（边长 = 墨迹最大边 × 1.2），美术路径一字不动，只改可视窗口。这样每个图标的"最大墨迹边"相等、各自居中，横向图标（邮箱/微信）高度自然偏小但不再突兀。
- 实现要点：早期用根 `<svg>` 的 `transform` 属性方案在 Chrome 不可靠（实测墨迹仍不齐），改用 **viewBox 重写**后稳定。Chrome 实测（`verify-inks.cjs`，getBBox → 按容器比例折算）四方向一致：五个图标墨迹最大边**全部 = 7.93px**（demo 纸面 0.68 缩放下 9.52px 容器 ÷ 1.2）。

**② 首屏纸面改为 v34 抽取源：**

- round 01 首屏纸面是手搓简化版（`.section-title` 下边框标题、Times 衬线、4px 圆点 bullet、硬三栏），与 v34 真实渲染不符。
- 本轮用 `extract-v34.cjs` 从 v34 直接抽取渲染后的 `#paper-content` innerHTML + 精选纸面 CSS（白名单剥离编辑器交互态），注入四个首屏替换手搓纸面；`re-inject-inner.py` 幂等替换，`build_explorer.py manifest.json --force` 重建 `style-explorer.html`。
- 首屏纸面现为 v34 真实结构：section 深灰胶囊标签、entry-head 三栏（岗位｜公司｜日期）、`•` CSS bullets、run-zh/en/num 字体分轨、`｜` 全角分隔符、光学归一图标。四个方向**仅换纸面、保留各自外围 chrome**（背景/按钮/顶栏/缩放控件不变）。

**边界（未触碰冻结规则）：** v34 图标美术路径、纸面盒模型与字号规则（L-06/L-09/L-11/L-19）、A4 边距等一律未改；本轮只做图标渲染归一 + demo 纸面换源。磁盘 `v34-paper-core.css` 仍含 3 条编辑器态 `.paper-content` 规则（参考件，与已注入 demo 的修正版略有出入，未强改以免影响已注入结果）。
