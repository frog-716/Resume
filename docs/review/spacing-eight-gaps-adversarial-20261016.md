# 八处排版数值的独立对抗审查

> 状态：审查建议与试用公式，不是已确认规则。用户只确认“经历三栏到本段第一条要点”的空隙应一起自动调整；系数与自动排布顺序仍待看演示确认。

## 先说结论

- 旧版三栏标题虽然比正文大半号，但行高公式有机会让它占的高度反而更小。审查建议在演示里把三栏行高从 `1.30` 改试 `1.35`。
- 经历标题到第一条要点原来固定空 4px。建议试 `正文大小×0.28`：10.5号字时约3.92px，跟原来几乎一样；8.5号字时约3.17px。
- 八个数值可以先用同一个“松紧”一起放大。短稿不硬撑空隙；长稿先找最大可用字号，再放宽空隙靠近页底。该算法没有用真实PDF完成全面校准。
- 第一个分区前，联系方式到标题分隔线中心的18.5px必须保持固定，不能跟着松紧变化。

## 审查范围与限制

独立子代理只读检查了产品规格和第三十版演示，未访问私人简历。它没有运行浏览器或导出PDF；本文记录的是公式推导和代码结构检查，不把“看起来最好”说成已经实测证明。

主审查检查了新演示：直接在本机 `http://127.0.0.1:8766/a4-spacing-eight-gaps-demo-v31.html` 打开、编辑合成要点后，字号会重新适配，纸面 1–8 号位置都能显示。此项仅为原型运行检查，不是Mac正式App或真实PDF验收。

## 八个位置与建议数值

`s` 表示正文实际字号，单位pt；`u=0` 是最紧，`u=1` 是各处最多放宽25%。以下全部是试用值。

| 编号 | 纸面位置 | 新版试用算法 |
|---|---|---|
| 1 | 正文这一行到下一行 | 行高倍数 `1.375 + 0.075u` |
| 2 | 三栏标题换到下一行 | `(s + 0.50) × (1.35 + 0.05u)` |
| 3 | 同组要点之间 | `0.158s × (1 + 0.25u)` pt |
| 4 | 上个板块到下个板块标题 | `min(0.789s × (1 + 0.25u), 10)` pt |
| 5 | 大标题到第一条要点 | `0.36s × (1 + 0.25u)` pt |
| 6 | 大标题到第一段三栏 | `0.57s × (1 + 0.25u)` pt |
| 7 | 上一段经历最后要点到下一段三栏 | `0.37s × (1 + 0.25u)` pt |
| 8 | 三栏到这一段第一条要点 | `0.28s × (1 + 0.25u)` pt |

第8处的 `0.28` 是从旧样式附近推出来的：旧4px约等于3pt；`3÷10.5≈0.286`。用0.28后，10.5pt时是2.94pt，约3.92px；8.5pt时是2.38pt，约3.17px。它能保留原来的视觉尺度，同时让字号缩小时空隙也收窄。

在 `s=10.50pt、u=0` 时，八项分别为：正文行高14.44pt、三栏行高14.85pt、要点间1.66pt、板块间8.28pt、大标题到要点3.78pt、大标题到三栏5.99pt、经历间3.89pt、三栏到要点2.94pt。

## 为什么改三栏行高试用值

旧公式是正文行高 `1.375s`、三栏行高 `1.30(s+0.50)`。两者在 `s≈8.67pt` 时一样高。字号再大时，三栏标题本身字更大，行高却更矮：

| 正文字号 | 正文行高 | 旧三栏行高 | 新三栏试用值 |
|---:|---:|---:|---:|
| 8.50pt | 11.69pt | 11.70pt | 12.15pt |
| 9.50pt | 13.06pt | 13.00pt | 13.50pt |
| 10.50pt | 14.44pt | 14.30pt | 14.85pt |

改为 `1.35` 后，三栏行高在8.50–10.50pt范围一直略高于正文行高，修正了倒挂。这个层级是数字事实；1.35看起来是否更舒服仍需用户看纸面确认。

## 自动排版试用顺序

1. 先用10.50pt、`u=0`试排。放得下就停；短稿不为填满纸面把行距和空隙撑大。
2. 放不下时，在最紧空隙下，把字号从大到小找出最大能放下的字号。
3. 找到后，再慢慢提高`u`，让八个数值一起放宽；仍放得下的最大`u`就是这一稿使用的值。
4. 8.50pt、`u=0`仍放不下时，完整保留文字并暂停PDF导出。

这种顺序先保住字号，再用空隙填剩下的白纸。实际测量应使用浏览器真实换行，不按字符数估算。

## 代码核查发现

- 第三十版条目标题确实有固定4px下内边距；把它改为动态值时，应直接替换这段内边距，不能再给下面的要点额外加同一段距离，否则会算两次。
- 第三十版的大标题到三栏的动态空隙只套用在工作/项目经历容器，教育背景没有套上。第三十一版原型已补上教育背景。
- 第三十版首个分区标题有单独CSS规则；联系方式到第一个分区标题的18.5px距离不受一般板块间距控制。第三十一版继续保留固定值。
- CSS里的点数换成像素时使用 `1pt = 4/3 CSS px`，单位换算正确。第三十一版测可用纸高时使用小数高度，避免整像素读数吃掉一小段容量。

## 还不能声称的事

- 这些系数没有经过不同经历数量、要点长短、真实字体和PDF的完整组合测试，不能称为“最佳比例”。
- 共同松紧`u`最多放宽25%是便于试验的建议值，不是用户确认的范围。
- 三栏行高1.35和第8处0.28是待试用值，不覆盖用户之前确认的固定字号、字体、边距、18.5px联系区距离或编辑功能。
- 第三十一版是讨论原型，不是正式App，也不改动生产规格或真实简历数据。
