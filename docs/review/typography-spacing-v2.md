# 第二轮字号与留白审查

2026-10-11。两项全新subagent使用`fork_turns=none`，只接收本轮精简约束，不读取前序对话、文件或私人资料，不执行代码。建议待用户选定，不是行业标准。

## 固定字号与留白

建议姓名18pt、联系方式9pt、分区12pt固定；正文上限10.5pt，防止派生条目11pt以上逐渐超过固定12pt分区标题。常见联系内容两行；固定字号与固定宽度不能容纳任意长度，需在允许分组换行与坚持两行后由用户调整显示文字之间选择。上下内边距先上12mm下10mm，必要时在10–14mm内有限浮动；内容短时末尾剩余留白可能大于此范围，不能把两种留白混为一谈。

## 颗粒度与字号关系

另一项建议默认0.1pt细调、0.5pt粗调、自动拟合按0.01pt找最大可容纳值；0.25pt可对照。用百分之一磅整数计算正文和＋50的条目/日期，避免累计误差。原稿字号差额不是0.5pt，新规则需明确规范化；演示可用正文8.87pt、条目/日期9.37pt。该审查员建议上限保留12pt，与前一项10.5pt建议有差异，演示提供对照，不由agent暗定。

## 本机字体核对

通过CoreText只读核对当前Mac已有PingFang SC、Songti SC、Heiti SC、Times New Roman、Arial、Georgia、Helvetica Neue、Courier New、Avenir Next。演示中文提供同源思源黑体、苹方、宋体、黑体；英文与数字分别提供经典衬线/无衬线/等宽候选。运行时检查所选字体可加载，缺失时提示而不默默替代。中文同源字体内置，系统字体不复制或重新分发；正式字体选定与PDF一致性验收另行完成。

正式规则唯一维护在根目录`SPEC.md`。
