# 工作事项标签

Matt Pocock 的技能会用五种固定标签角色。本表说明它们在本仓库里对应哪个 GitHub 标签，以及什么时候使用。

| 技能里的标签 | 本仓库的标签 | 大白话意思 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 新来的事项还没判断，等维护者先看一眼、决定怎么处理。 |
| `needs-info` | `needs-info` | 说明不够，正在等提事项的人补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 事情说清楚了，可以交给 AI 助手开始处理。 |
| `ready-for-human` | `ready-for-human` | 需要人亲自处理或做决定。 |
| `wontfix` | `wontfix` | 已决定不处理这件事。 |

Skill 提到某种角色时，使用表中对应的 GitHub 标签。标签只标记工作事项的处理状态，不是 Resume App 的功能，也不是简历字段。
