# 领域文档怎么读

工程技能在查看或修改项目时，按下面的顺序查阅项目术语和重要决定。

## 开始前阅读

- 先读根目录的 `GLOSSARY.md`。如果以后出现 `GLOSSARY-MAP.md`，按它找到与当前工作相关的术语表。
- 查看与当前工作有关的 `docs/adr/` 决策记录；只读相关内容即可。
- 如果这些文件不存在，继续工作即可，不必先补文档。

本仓库目前是**单一业务上下文**：术语表在根目录，工程决定在 `docs/adr/`。

## 沿用项目用词

在 Issue、方案、代码或说明中提到项目概念时，优先使用 `GLOSSARY.md` 中已有的名称。不要随意换成容易混淆的近义词。

如果遇到术语表还没解释的概念，先确认它是不是项目真的需要的新概念；需要时再补充术语表。

## 遇到决定冲突时

如果准备做的事情与某条 ADR 决定不一致，先指出冲突及对应 ADR，再说明为什么可能需要重新讨论；不要默默绕过旧决定。
