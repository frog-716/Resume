# Gemini 4 Argon 任务模式 · 本轮探索提示

请为一款仅本人在 Mac 本机使用的轻量简历 App，探索 3 套真正不同的整体 UI/UX 方向，并在当前 Gemini 对话中提供可直接查看的设计预览。三套方向要能切换，差异来自布局、交互组织和视觉层级，不要只换颜色，也不要增加产品没有的功能。

如果当前任务模式不能生成可见、可操作的界面预览，请直接说明限制并停止；不要切换到其他模式，不要创建 Google 文档、幻灯片或其他云端文件，也不要用大段文字或源码冒充预览。不要调用其他应用，不需要附件。

## 本轮页面与状态

三个方向都要覆盖：

- 以三列卡片为主的简历收藏馆，可滚动；窄窗口时按可读性收为一列。卡片展示当前稿或快照、所属简历、名称和精确到分钟的时间。卡片用铅笔图标改名；点纸面进入当前稿，点旧快照则复制为一份新简历。
- A4 编辑页及必要的排版面板。A4 纸面保持原有布局，不随窗口变窄重排。
- 点击编辑页左上角简历名称可直接改名；页面不显示产品名或改名铅笔。
- ⌘F 进入同一个收藏馆并聚焦搜索框，按名称搜索；无结果时给简短提示。Esc 退出收藏馆回编辑页。
- ⌘S 是唯一创建命名快照的入口，打开简洁的命名弹窗；没有单独的“保存版本”按钮。当前稿自动保存，不要让用户误以为 ⌘S 才保存正文。
- 快照只读，名称和创建时间固定，内容包含正文、身份、链接和版面。要继续编辑旧快照时，完整复制成新简历，默认名称为“原名称（副本）”；不能修改或覆盖旧快照和原当前稿。
- 保存中、已保存、失败重试、收藏馆空态与无搜索结果；保存状态只能作为原型模拟，明确不代表真实本机持久保存。
- 收藏馆提供低频废纸篓入口；快照可逐条还原、逐条彻底删除或一次清空，彻底删除和清空前确认。简历支持新建、改名和复制。编辑页保留“导出 PDF”入口，不设计其他导出格式。

## 已确认的产品与纸面约束

- 产品不接入 AI、不做岗位匹配、公司管理、账号、云同步或模板市场。Gemini 只用于本次外部设计探索。
- 纸面只用虚构简历资料，不改变原有 A4 结构：四块固定为专业技能、工作经历、项目经历、教育背景；四边固定留白 9mm；姓名 18pt、联系方式 8.5pt 且固定两行、分区标题 12pt；正文自动适配 8.5–10.5pt，条目标题和日期始终比正文大 0.5pt；中文苹方、英文和数字 Times New Roman；工作/项目三等栏，教育 1:3:1；保留来源 GitHub 白猫图标。
- 联系区第一行是电话/邮箱/微信，第二行是 GitHub/个人网页；后二项可选。展示示例时只用合成信息，勿编造真实联系方式或链接。
- 页面观看只提供“100%”和“整页”。固定板块不删除、不换序；要点和工作/项目整段经历按已确认范围排序。粘贴只保留文字。
- 四种自动间距的上下限及自动排布先后仍待确认；不要把候选数值写成已批准规则，不设计可改变固定 9mm 留白的控件，也不要凭空填入用户未确认的参数。
- PDF 是唯一导出格式。真实保存、快照恢复及 PDF 导出都不在原型中实现；界面必须清楚标明仅为模拟。

## 示例与视觉表达

仅使用合成内容，例如“林舟”“数据方向”“运营方向”“第一稿”“投递版”和示例时间。所有中文文案使用自然、简短的大白话。主工作区突出 A4 纸面，兼顾较窄 Mac 窗口；不要把产品规格长文塞进实际产品界面。

每个方向配一行简短说明，重点让我能在预览里切换方向、搜索、打开快照、试 ⌘S 命名框和查看保存失败状态。不要只给文字、静态图或源码。
