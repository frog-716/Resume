# Resume 编辑与版本界面 · Gemini 设计简报

状态：2026-10-16起进入正式App实现与验收；Gemini作为UI/UX顾问提供界面建议，产品行为仍以`SPEC.md`为准。用户于2026-10-11明确要求在UI开发中使用Gemini顾问。

## 本轮目标与合同

个人 Mac 本机使用的轻量简历编辑器。每份简历只有一个自动保存的当前稿，可有多个永久只读快照。⌘S 是唯一的命名快照入口；自动保存不制造快照。打开旧快照会完整复制成一份新简历，不能覆盖旧快照或原当前稿。

本轮以三列简历收藏馆为界面主体，同时探索 A4 编辑页、搜索/无结果、⌘S 命名弹窗、保存状态/失败重试、创建/改名/复制、废纸篓等必要界面和状态。收藏馆可滚动，卡片按更新时间从新到旧；名称旁用铅笔图标改名。点击纸面进入当前稿或按规则复制快照。⌘F 进入同一收藏馆并聚焦搜索框，Esc 退出。编辑页左上角简历名称可直接改名；页面不显示产品名、改名铅笔或快捷键提示。

探索三套实质不同的整体方向，每套覆盖上述页面/状态；差异来自布局、交互组织和视觉层级，不靠换色凑数，也不增加 AI、岗位、公司、账号、云同步或模板市场。以 Mac 桌面为主，兼顾窄窗口；在 Gemini 当前对话中提供可实际查看的预览，不用文字或源码冒充可见稿。

## 不可改变的纸面约束

纸面只用虚构样稿，保持单张 A4 和原有结构：四边留白固定9mm；四块固定为专业技能、工作经历、项目经历、教育背景。姓名18pt、联系方式8.5pt且严格两行、分区标题12pt；中文苹方、英文/数字Times New Roman；正文8.5–10.5pt并以0.01pt精度自动缩放；条目标题/日期始终为正文+0.5pt，标题固定粗体、日期正常字重；工作/项目三等栏，教育1:3:1。保留来源 GitHub 白猫图标。

留白不可调。自动排版的四种间距范围和算法顺序仍待用户确认；不要把候选数值当已批准规则，也不要加入固定边距控件。自动排版不能改写或裁掉文字；最低字号仍超页时保留全文并暂停 PDF 导出。要点和工作/项目经历依已确认范围排序，⌘Z 撤销稿件编辑。只提供“100%”和“整页”两种观看方式，不因窗口变窄重排 A4 纸面。

## 本机保存与原型边界

Resume 独立保存资料和发版，不依赖 Career/Career-Next 工作目录。PDF 是唯一导出格式，正式版保存到 Mac“下载”文件夹。原型可模拟交互，但必须清楚说明模拟保存和模拟导出不能证明真实本机持久化或 PDF 验收通过。
