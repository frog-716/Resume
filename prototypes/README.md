# 简历 A4 交互演示

这是用来核对未定排版细节的单文件网页原型，不是正式 Resume App，也不代表生产验收。

## 打开

用浏览器打开 [方案二自动排版演示](a4-spacing-algorithm-demo-v15.html)或[第十四版简历编辑演示](a4-typography-demo-v14.html)，无需安装或构建。第十五版专门比较自动排版算法；第十四版演示编辑、快照与收藏馆。页面都只用虚构简历，不会保存到磁盘。

## 第十五版：在第十四版原稿上比较方案二

- 第十五版完整沿用第十四版的简历、白猫图标、联系方式、四个固定栏目、版式和编辑界面；没有另做一份简化简历。新增内容只有“方案二”对比弹层。
- 点击左侧“查看两种纸面效果”，会把编辑页当前简历文字复制到两张预览纸上，不改动编辑页内容。
- 左边“更铺满”、右边“留些白纸”可以分别调纸底目标（默认3mm和18mm），再点“重新比较”。
- 弹窗用三句话说明排版：试不同字大小和空隙；放不下全文的排法不选；再从能放下的里面挑一种。想了解更多时可展开说明。每种间距试紧凑/中间/宽松三档，共最多81种搭配；实际测量后，预览显示选中的字号、四种间距和剩余白纸。
- 为了让两种目标可见差异，演示暂按“字号50%、间距30%、纸底空白20%”比较。这些比例、三个档位和纸底目标仍是待讨论的演示值，不是冻结规则，也不会写进 `SPEC.md`。
- 第十五版其余编辑行为沿用第十四版原稿；两版都只在网页内存中运行，不会持久保存。第十四版原文件不变。
- 打开方式：双击HTML文件，或将文件拖入浏览器。页面不依赖本地服务器。

## 当前只展示待确认的内容

- 四边留白固定9mm；页面只显示“页边距 9mm”，没有调节控件。自动排版只调整正文大小和四种间距。
- 四个滑块是讨论用的候选范围：正文行距、三栏换行行距、要点之间的空隙、分区之间的空隙。拉动后可看纸面和实际数值变化；正式版确认后会由程序自动调整，不要求用户逐项操作。
- 第十四版仍展示旧的共同进度排布候选；新的联合候选逻辑只在第十五版独立演示。两版都不是已确认规则。
- 点选一个要点或工作/项目经历的任一栏，纸面左侧留白里会出现32px鼠标图标；从图标拖动可移动选中内容。文字本身仍用于选择和编辑。当前网页验证普通鼠标拖动；真实Mac三指触控操作还要在正式App验收。
- 点击“导出 PDF”会打开系统打印窗口，按A4输出当前稿；演示版没有直接写入Mac“下载”文件夹。

快照只保存内容，不随附PDF。正式版需要PDF时从编辑页导出。正式产品规则以根目录 [SPEC.md](../SPEC.md) 为准；每版变化记在 [CHANGELOG.md](CHANGELOG.md)。
